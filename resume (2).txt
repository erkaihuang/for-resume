## 一、项目是什么

这是一个基于 **Hypium/DeviceTest 自动化测试框架** 的 **Connectivity（无线连接）综合测试项目**，用于对智能终端设备（手机/平板等）进行**多协议、多场景的自动化连接能力测试**。

### 核心技术栈

| 层面 | 技术 |
|------|------|
| 测试框架 | Hypium / DeviceTest（自研 Python 自动化测试框架） |
| 设备控制 | ADB（Android）、HDC（OpenHarmony）、串口、TCP/IP 远程控 |
| 编程语言 | Python 3 |
| 配置管理 | XML 配置文件驱动 |
| 报告系统 | HTML 报告 + 日志收集 + BugReport 自动抓取 |
| CI/集成 | MQ 消息队列上报、TICC 服务器对接 |

### 测试覆盖的无线协议（6大模块）

1. **1_Atomic_Ability** — 原子能力测试：BLE（蓝牙低功耗）、BR（蓝牙经典）、SLE（星闪近场通信）
2. **2_BGLE** — BT_BLE 共存、GLE（星闪增强）测试
3. **4_GNSS** — 卫星定位/GPS 测试
4. **5_WIFI** — WiFi 功能与性能测试
5. **7_Infrared** — 红外遥控测试
6. **8_Coex** — 多协议共存/干扰测试（COEX_FUNCTION + COEX_PERFORM_CIDA）

### 硬件设备生态

通过 `user_config_001.xml` 可以看到，测试环境涉及 **10+ 种硬件设备**：

- **DUT 被测机**：OpenHarmony 手机（通过 HDC 连接）
- **M7600**：射频综测仪（安立）
- **TurnTableControl**：电动转台（360°旋转，用于 OTA 角度测试）
- **AntiInterferenceSceneControl**：抗干扰场景控制器
- **BizAP1**：WiFi AP（接入点），支持 2.4G/5G、EAP 认证
- **蓝牙设备**：Jabra 耳机、华为 FreeBuds Pro 3/5、罗技鼠标、华为鼠标 CD26
- **星闪设备**：SLE Mouse
- **BLE 设备**：荣耀手环

### 架构亮点

- **`devicetest` 框架**：自研的完整测试运行器，包含 TestRunner → TestCase → TestMethod 三层结构，支持 setup/teardown、结果上报、日志收集、截图、BugReport 自动抓取
- **`aw` 目录**：20+ 种硬件设备的驱动适配层（AW = AutoWare），每个设备一套独立的控制脚本
- **`controllers`**：设备控制器抽象层（Android、ADB、UIAutomator、Monkey 等）
- **`agent`**：CI 对接层（MQ 消息队列、TICC 服务器上报）
- **主测试流**：`main_test.py` 通过 `xdevice` 框架按角度（0°~300°，30°步进）批量执行 OTA 方向性测试

## 简历详细描述

### 项目经历

> **蓝牙/星闪耳机 OTA 抗干扰自动化测试系统** | 独立开发 | 202X.XX – 至今
>
> 面向 2T2R（2发2收）蓝牙/星闪耳机，基于自研 Hypium 自动化测试框架，独立设计并实现了完整的 OTA 带内共存（ICO, In-band Coexistence）抗干扰量化测试体系，覆盖 SparkLink 专有协议与星闪（SLE, SparkLink Evolution）双协议栈。
>
> **核心工作：**
>
> **1. 抗干扰量化测试用例开发（60+ 测试用例）**
> - 设计并实现了基于**功率扫描法**的抗干扰能力量化评估方案：通过 Keysight M7600 射频信号发生器在 2442MHz 注入 DPSK 调制（80MHz 带宽）的带内干扰信号，从 -48dBm 到 +52dBm 以 1dBm 步进递增，自动检测音频卡顿临界点
> - 卡顿判定算法：实时解析耳机端 `tx_flushed`（发送缓冲区溢出）、`total_tx_size`（吞吐量）、`ackrate`（ACK 确认率）三项核心指标，`tx_flushed > 0` 即判定为卡顿，精准定位抗干扰边界
> - 实现 **TxBF（Transmit Beamforming）波束成形码字遍历**测试：遍历 0~511 共 18 个码字（步长30），每个码字对应不同波束方向，全面评估各方向下的抗干扰性能差异
> - 开发**自适应码字无干扰基线测试**（`C2T2R_adaptive`），在无干扰理想环境下采集传输性能基准数据，用于对比分析干扰场景下的性能衰减
>
> **2. 360° OTA 方向性测试自动化**
> - 通过电动转台控制耳机以 **30° 步进旋转（0°~300°共12个角度）**，结合 M7600 固定方向干扰注入，实现全方向 OTA 覆盖测试
> - 开发代码生成脚本（`_gen_sle.py`），基于模板自动批量生成角度参数化的测试用例文件，覆盖 C2T2R 和 SLE 两大系列共 **50+ 个角度变体**，大幅提升用例维护效率
>
> **3. 双协议栈（SparkLink + 星闪 SLE）测试覆盖**
> - **SparkLink 协议**：基于 L2HC 960kbps 高清音频编解码，支持 7 档/8 档发射功率切换，验证 TxBF 波束赋形下的抗干扰能力
> - **星闪 SLE 协议**：基于固定比特率 320kbps，独立实现 `switch_sle_power()` 功率控制，覆盖 7 档/8 档双功率级别的全角度测试
> - 两套协议共享同一套硬件控制链路和日志分析框架，通过协议抽象层实现代码复用
>
> **4. 射频参数配置与校准自动化**
> - 实现 INI 配置文件远程修改能力，自动化调整耳机内部射频参数：
>   - `txbf_power_backoff_2g`：TxBF 功率回退策略（支持设置为 0 不回退 / `0xCE00CE00` 特殊模式）
>   - `bt_online_cali_switch`：蓝牙在线校准开关（`0x80000000` 启用校准 / `0x80000002` 特定校准模式）
> - 配置修改后自动触发设备重启并等待稳定，确保参数生效后再执行后续测试
>
> **5. 大人流场景定量抗干扰测试**
> - 开发 `AntiInterferenceBT_Quantitative4` 定量测试用例，覆盖 7 档/8 档双功率、多码字组合，每个功率点采集 60 秒日志
> - 实现**卡顿/不卡顿对照组机制**：自动记录卡顿临界点及其前后各一个对照点的完整日志，生成对比文件夹，便于后续根因分析
>
> **6. 自动化报告与数据管理**
> - 测试结果实时写入 Excel（`卡顿测试结果.xlsx`），包含档位、码字、干扰功率、卡顿状态、吞吐量、ACK 率等完整数据
> - 自动生成 `报告数据.xlsx` 汇总报告，仅保留卡顿点及对照点，方便快速定位问题
> - 日志自动归档：按测试用例创建独立归档目录，卡顿/不卡顿日志分文件夹复制管理
